# Prospector de Sites para Codex

Plugin de prospecção de clientes para sites, adaptado para funcionar com o Codex.

## Fluxo incluído

1. Configuração inicial
2. Busca e organização de prospects
3. Redesenho e edição de previews
4. Publicação
5. Proposta comercial por e-mail
6. Tratamento de respostas
7. Follow-ups
8. Contrato
9. Painel e histórico de leads

## Estrutura

- `.agents/plugins/marketplace.json`: catálogo do plugin
- `plugins/prospector-de-sites/.codex-plugin/plugin.json`: manifesto
- `plugins/prospector-de-sites/skills/prospector/`: instruções, referências, recursos e scripts

## Segurança

Não coloque senhas, chaves de API ou dados reais de clientes no repositório. Use o arquivo de exemplo apenas como modelo e mantenha segredos fora do GitHub.
